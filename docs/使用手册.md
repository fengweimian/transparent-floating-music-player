# 小风音乐 使用手册

> 版本：v3.2.20 ｜ 适用平台：Windows ｜ 更新日期：2026-08-11

---

## 一、软件简介

**小风音乐** 是一款全透明、无边框的桌面悬浮音乐播放器。它以全屏透明窗口覆盖在桌面上，背景自动轮播图片/视频幻灯片，歌词居中显示，音乐在"氛围感"的场景中持续播放。

### 核心特性

- 🖥️ **全透明无边框桌面挂件**：窗口置顶、自动隐藏控制栏，不遮挡桌面内容
- 🎵 **本地音乐播放**：支持 8 种常见音频格式
- 🔍 **多平台在线搜索**：网易云 / QQ 音乐 / 歌曲宝 三个来源
- 📋 **歌单管理**：导入网易云、QQ 音乐歌单（支持分享短链），新建/管理自己的歌单
- 💬 **歌词显示**：LRC 解析 + **卡拉OK式逐字扫光**（QQ 音乐 / 网易云自动获取逐字数据），支持翻译（网易云）
- 🖥️ **桌面歌词**：独立置顶悬浮窗口，带控制栏与完整样式设置
- 🔑 **双平台账号登录**：网易云 / QQ 音乐登录后可用「我的歌单」「每日推荐」等
- 🖼️ **全屏幻灯片背景**：图片 + 视频混合轮播，多种转场效果
- ⬇️ **在线下载**：一键下载歌曲（音频 + 歌词 + 封面）

## 二、安装与启动

### 方式一：安装版（推荐）

从 [GitHub Releases](https://github.com/fengweimian/transparent-floating-music-player/releases) 下载最新安装包：

- `XiaofengMusic-Setup-3.2.25.exe`（推荐）
- 支持自定义安装目录（安装向导中可选）
- 默认创建桌面快捷方式和开始菜单快捷方式
- 双击桌面快捷方式即可启动

### 方式二：免安装版（便携）

绿色版已解压目录：`dist/win-unpacked/`

直接双击其中的 `小风音乐.exe` 即可运行，无需安装。

### 方式三：开发模式

需要 Node.js 环境，在项目根目录执行：

```bash
npm install   # 首次运行需安装依赖
npm start     # 或 npm run dev
```

## 三、首次使用

**首次启动**时，由于尚未设置任何文件夹，软件会自动弹出「设置」窗口。建议按以下顺序完成初始配置：

1. **音乐文件夹**：选择存放音乐的文件夹（如 `D:\Music`）
2. **图片/视频文件夹**（可选）：选择幻灯片背景素材文件夹
3. **下载目录**（可选）：设置在线下载歌曲的保存位置
4. 点击右下角 **「保存并应用」**

配置完成后，主窗口会自动开始播放音乐文件夹中的第一首歌曲，并以图片/视频作为背景轮播。

> 💡 之后随时可以点击控制栏的 ⚙ 按钮，或托盘菜单中的「设置」重新打开设置窗口。

## 四、界面总览

播放器是一个**全屏透明置顶窗口**，从上到下依次为：

| 区域 | 说明 |
|---|---|
| 背景层 | 图片/视频幻灯片，带转场效果和遮罩 |
| 歌词区 | 居中显示的歌词，逐行高亮 + 卡拉OK式扫光 |
| 曲目信息 | 顶部显示的当前歌曲名 |
| 控制栏 | 屏幕**底部**，鼠标移入后出现，移开 3 秒自动隐藏 |
| 专辑封面 | 播放本地音乐时，右上角显示封面 |
| 登录入口 | 右上角，网易云 / QQ 音乐两个独立登录入口 |

### 控制栏的显示/隐藏

- 鼠标移动到**屏幕底部区域** → 控制栏淡入
- 鼠标离开底部 → 约 3 秒后自动隐藏
- 键盘操作（空格、方向键等）会临时唤出控制栏

### 播放列表面板 & 搜索面板

- 点击控制栏的 **📃**（播放列表）按钮或按 `Ctrl+P` 打开播放队列
- 点击控制栏的 **🔍**（搜索）按钮或按 `Ctrl+F` 打开在线搜索/我的歌单面板

## 六、本地音乐

### 支持的音频格式

`mp3` `wav` `ogg` `flac` `m4a` `aac` `wma` `opus`

### 使用方法

1. 在设置中配置「音乐文件夹」
2. 软件自动扫描文件夹内所有支持的音频文件并排序
3. 「我的歌单」标签页中会出现置顶的 **「本地音乐」** 歌单
4. 点击「加载」即可将本地音乐载入播放队列

### 专辑封面自动查找

播放本地歌曲时，软件会按以下顺序自动查找封面：

1. 与歌曲**同名的图片**（如 `晴天.mp3` → `晴天.jpg`）
2. 通用封面名：`cover` / `folder` / `album` / `front` / `artwork` / `albumart`
3. 文件夹中**第一张图片**

## 七、在线搜索

点击控制栏 🔍 按钮（或 `Ctrl+F`）打开搜索面板。

### 搜索来源

| 来源 | 说明 |
|---|---|
| 网易云 | 优先走网易云官方 API，搜索结果质量最好 |
| QQ 音乐 | 使用 Meting 的 tencent 源 |
| 歌曲宝 | 聚合站，提供 mp3 直链 + 完整歌词 |

### 搜索步骤

1. 选择搜索来源（默认网易云）
2. 输入歌曲名 / 歌手 / 关键词
3. 点击「搜索」或按回车
4. 面板底部显示结果数量，如 `找到 30 首歌曲`

### 搜索结果操作

每条结果右侧有 4 个按钮：

| 按钮 | 功能 |
|---|---|
| 播放 | 立即播放该歌曲（并加入播放队列） |
| 加入队列 | 仅加入播放队列，不打断当前播放 |
| 下载 | 下载到设置中配置的下载目录 |
| 加到歌单 ▾ | 弹出菜单，选择要加入的歌单 |

- **双击**搜索结果行 = 立即播放
- 搜索面板会在播放后自动关闭

## 八、歌单管理

搜索面板内有「搜索」和「我的歌单」两个标签页。「我的歌单」页分为三个独立模块：

```
┌────────────────────────────────────┐
│ 我的歌单（本地/导入）   [+ 导入歌单] [+ 新建歌单] │  ← 本地/导入歌单
├────────────────────────────────────┤
│ 网易云歌单（登录后显示）                │
├────────────────────────────────────┤
│ QQ音乐歌单（登录后显示）               │
└────────────────────────────────────┘
```

### 本地 / 导入歌单

#### 新建歌单

1. 点击 **「+ 新建歌单」**
2. 输入歌单名称，点击「创建」

#### 导入歌单（网易云 / QQ 音乐）

1. 点击 **「+ 导入歌单」**
2. 粘贴歌单链接，软件自动解析预览歌曲列表
3. 确认后点击 **「全部添加」** 保存为歌单

**支持的链接格式：**

- 网易云：`https://music.163.com/playlist?id=123456789`
- QQ 音乐：
  - `https://y.qq.com/n/ryqq/playlist/123456789`
  - `https://i.y.qq.com/n2/m/share/details/taoge.html?id=123456789`
  - 分享**短链**（`https://c6.y.qq.com/...`，会自动跟随跳转解析）

导入的歌单会**自动获取官方歌单名**作为默认名称，可在导入前修改。

> 💡 导入功能可导入**任何人的公开歌单**（朋友分享的、网上找的），且**无需登录**——这是登录歌单替代不了的能力。

### 网易云歌单（需登录）

登录网易云后，「我的歌单」模块自动显示你的所有歌单，含"我喜欢的音乐"红心歌单（♥ 标记排最前），点击「播放」即载入整单播放。详见第十三章。

### QQ音乐歌单（需登录）

登录 QQ 音乐后，自动显示你**创建的 + 收藏的**歌单（合并去重，红心置顶），点击「播放」即载入整单播放。详见第十四章。

### 歌单操作

- **展开/收起**：点击歌单卡片标题栏
- **加载**：将歌单全部歌曲载入播放队列并开始播放
- **移除歌曲**：展开歌单后，点击歌曲右侧 ✕
- **删除歌单**：点击歌单卡片右上角 ✕（本地音乐歌单不可删除）

### 播放队列

- 控制栏 📃（或 `Ctrl+P`）打开播放列表面板
- 面板显示当前队列歌曲数量和列表
- **「清空在线」**：一键清空所有在线歌曲（本地音乐不受影响）

> 💡 加载歌单、播放搜索结果都会往播放队列追加歌曲，队列是"一次会话"级别的，关闭软件后清空；而「我的歌单」会持久保存。

## 九、下载歌曲

### 前提条件

必须先在**设置**中配置「下载目录」，否则会提示 `请先在设置中配置下载目录`。

### 各来源下载内容

| 来源 | 下载内容 | 格式 |
|---|---|---|
| 网易云 / QQ 音乐 | 音频 + 歌词 + 封面 | `.mp3` + `.lrc` + `.jpg` |
| 歌曲宝 | 音频 + 歌词 | `.mp3` + `.lrc` |

### 文件命名规则

```
歌手 - 歌曲名.mp3
歌手 - 歌曲名.lrc
歌手 - 歌曲名.jpg
```

> 若目标文件已存在，会提示「文件已存在」并跳过，避免重复下载。

### 下载进度

下载时搜索面板底部会显示进度：

```
⬇ 正在下载: 歌手 - 歌名.mp3 ...
✅ 下载完成! 歌手 - 歌名 (3.4MB)
```

## 十、幻灯片背景

在设置中配置「图片/视频文件夹」后，背景即开始轮播。

### 支持的素材格式

| 类型 | 格式 |
|---|---|
| 图片 | `jpg` `jpeg` `png` `gif` `webp` `bmp` |
| 视频 | `mp4` `webm` `mov` `avi` `mkv` |

### 切换间隔

设置中的「图片切换间隔」滑块，范围 **3 ~ 30 秒**（默认 8 秒）。

### 转场效果

内置多种随机转场：淡入淡出、放大（zoomIn）、左右/上下滑动、模糊进入等。

> 💡 提示：背景素材建议使用高清横屏图片（与屏幕比例接近），效果最佳。视频素材会自动静音循环播放。

## 十一、歌词显示

### 歌词来源

- **本地音乐**：自动读取同目录下的 `.lrc` 歌词文件
- **在线歌曲**：由各平台接口返回（网易云 / QQ 音乐自动获取歌词 + 翻译 + 逐字数据）

### 卡拉OK式逐字扫光（特色功能）

播放 QQ 音乐 / 网易云的歌曲时，软件会自动获取**逐字时间数据**（精确到毫秒），实现卡拉OK式扫光：

- 一束光带**从左到右连续扫过**整行歌词，正在唱的字"一半亮一半暗"
- 已播字 = 用户设置的颜色（默认红色），未播字 = 半透明暗色
- **无需登录**即可使用（数据来自平台服务端）
- 主窗口与桌面歌词**同步生效**

> ⚠️ 部分老歌/冷门歌本身没有逐字数据（平台侧不存在），这类歌只显示整行高亮，属正常现象。

### 歌词设置

| 设置项 | 范围 |
|---|---|
| 歌词字体 | 可选择系统中已安装的任何字体（默认字体） |
| 字体大小 | 14 ~ 40 px（默认 22 px） |
| 已播字颜色 | 逐字扫光的已播放字颜色（默认红色） |
| 显示翻译 | 开关，开启后在原文下方显示翻译（需来源支持） |

## 十二、桌面歌词

独立的置顶悬浮歌词窗口，播放时可挂在桌面任意位置。

### 开启方式

设置 → 「桌面歌词」区块 → 勾选「显示桌面歌词」→ 保存并应用。

### 控制栏

鼠标移到桌面歌词窗口**顶部边缘** → 控制栏浮现（不遮挡歌词）：

| 按钮 | 功能 |
|---|---|
| 🏠 打开主界面 | 显示并聚焦主窗口 |
| ⏮ 上一首 | 切换到上一首 |
| ▶/⏸ 播放/暂停 | 播放或暂停（图标随状态变化） |
| ⏭ 下一首 | 切换到下一首 |
| 🔒/🔓 锁定 | 锁定后窗口不可拖动（再点解锁） |
| ⚙ 设置 | 打开主设置窗口 |
| ✕ 关闭 | 关闭桌面歌词 |

- 窗口顶部**正中央**有一个 ✕ 关闭按钮，点击即关闭
- 桌面歌词窗口**可拖动**（锁定后不可），位置自动记忆在屏幕右下角附近

### 样式设置

| 设置项 | 说明 |
|---|---|
| 行数 | 单行（只显示当前句）/ 双行（当前句 + 上下句） |
| 对齐 | 居中 / 左 / 右 |
| 字体 + 字号 | 复用系统字体列表，14 ~ 72 px |
| 已播字色 / 未播字色 | 两个颜色选择器 |
| 文字透明度 | 30% ~ 100% 滑块 |
| 描边 | 文字加黑色描边（浅色背景下更清晰） |
| 覆盖任务栏 | 开启后置顶级别最高（可盖住任务栏） |
| 粗体 | 歌词文字加粗 |

所有设置在**主设置窗口**统一管理，保存即生效，桌面歌词窗口即时刷新。

## 十三、网易云登录（可选）

### 登录方式

1. 点击右上角 **「登录」** 按钮
2. 弹出登录窗口 → 用网易云 App **扫码**确认
3. 登录成功 → 右上角显示头像 + 昵称

> 登录走网易云**官方登录页**，安全可靠。登录态长期有效。

### 登录后可用的功能

悬停右上角头像 → 下拉菜单：

| 功能 | 说明 |
|---|---|
| 我的网易云歌单 | 展示我创建/收藏的歌单（含"我喜欢的音乐"红心 ♥），点击即播 |
| 每日推荐 | 今日推荐歌曲 30 首 + 推荐歌单 |
| 最近听过 | 本周 / 全部听歌记录切换，点击即播 |

也可在「我的歌单」页的「网易云歌单」模块中查看所有歌单。

### 听歌打卡

登录状态下，播放器里播放的**网易云歌曲**（每首 ≥ 60 秒）会自动上报到网易云：

- 计入网易云官方的"最近听过"记录
- 影响每日推荐算法（听得越多推荐越准）
- 无需任何手动操作，自动完成

## 十四、QQ 音乐登录（可选）

### 登录方式

1. 点击右上角 **「QQ登录」** 按钮（网易云入口旁）
2. 打开 QQ 音乐**官网登录页** → 用 QQ 扫码 / 账号登录
3. 登录成功 → 窗口自动关闭，右上角显示 QQ 头像 + 昵称

> 登录状态也会体现在**设置页**（「QQ音乐登录」区块，可查看/退出）。

### 登录后可用的功能

| 功能 | 说明 |
|---|---|
| 我的QQ音乐歌单 | 我创建的 + 我收藏的歌单合并展示（红心 ♥ 置顶），点击即播 |
| 每日推荐 | 新歌推荐 + 热门推荐歌单 |

### ⚠️ 登录态有效期

QQ 音乐官方对网页登录态限制较严：

- 登录态有效期约 **1 ~ 3 天**（视使用频率）
- 过期后功能会提示未登录，**重新登录**即可恢复
- 这是 QQ 音乐官方限制，无法延长

## 十五、设置项详解

| 设置项 | 说明 |
|---|---|
| 网易云登录 | 扫码登录 / 退出，显示头像昵称 |
| QQ音乐登录 | 打开 QQ 音乐官网登录 / 退出，显示头像昵称 |

## 十八、常见问题（FAQ）

**Q1：搜索不到结果？**
在线搜索依赖第三方接口，可能因网络、接口变动等原因失败。建议：① 检查网络连接；② 换一个搜索来源（如网易云搜不到换 QQ 音乐）。

**Q2：点击播放后没有声音？**
在线歌曲的播放地址由接口动态生成，部分歌曲可能因版权无法获取播放源。可尝试：① 换来源重新搜索；② 换一首歌曲；③ 检查音量设置。

**Q3：下载提示"请先在设置中配置下载目录"？**
打开设置 → 选择「下载目录」→ 保存并应用，即可正常下载。

**Q4：下载提示"文件已存在"？**
同名文件已在下载目录中，无需重复下载；如需覆盖请先手动删除原文件。

**Q5：控制栏找不到/消失了？**
鼠标移到**屏幕最底部**即可唤出；按键盘任意控制键（如空格）也会临时显示。

**Q6：如何完全退出播放器？**
点击控制栏 ✕ 按钮，或托盘图标右键 →「退出」。

**Q7：开机自启勾选了但没生效？**
确认保存时点击了「保存并应用」；另外部分安全软件可能会阻止自启注册。

**Q8：歌曲宝无法播放？**
这两个聚合站会动态刷新播放凭证，偶尔会失效。软件已内置一次自动刷新重试，若仍失败可稍后再试或换其他来源。

**Q9：某些歌没有逐字扫光？**
部分老歌/冷门歌在平台服务端没有逐字数据，只显示整行高亮，属正常现象（可换热门歌曲验证）。

**Q10：桌面歌词不显示 / 没有歌词？**
① 确认设置中已开启「桌面歌词」；② 播放的歌曲是否有歌词；③ 播放中开启桌面歌词时会自动同步当前歌曲，若仍无显示可尝试切下一首再切回。

**Q11：QQ 音乐功能提示未登录？**
QQ 音乐登录态有效期约 1~3 天（官方限制），过期后需重新登录：右上角「QQ登录」或设置页重新登录即可。

**Q12：桌面歌词窗口怎么关闭？**
鼠标移到窗口顶部 → 控制栏出现 → 点 ✕；或顶部正中央的 ✕ 按钮。
