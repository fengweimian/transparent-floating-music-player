# 歌词翻译「失灵」排查（v3.11.0）

> 排查时间：2026-11-07 · **仅排查，未改代码**

## 一句话结论

**接口没问题，经典模板也正常** —— 但 **t2 / t3 / t5 三个新版模板的歌词翻译从来没实现过**：
设置开关有效、翻译数据也确实取到了（存进了 `song.tlyric`），但渲染时从头到尾没被使用。

如果你是在模板五（或模板二/三）里觉得「开了翻译没反应」，那不是失灵，是这两条链路根本没接上。

## 3. 新版模板（t2 / t3 / t5）：❌ 翻译从没渲染过

同一首歌在模板五实测：

```
当前: 打上花火
存下的 tlyric 长度: 881     ← 数据拿到了！
歌词行元素: 3
翻译元素（.lrc-trans）: 0    ← 一个都没有
舞台文本: 编曲 : 米津玄師/田中隼人 | 制作人 : 米津玄師 | あの日見渡した渚を
```

### 根因：取到了、存下来了，但没人用

`renderer/template5/app.js:2150-2172`（t2:2114 / t3:2029 同构）：

```js
const r = await XFApi.lyric(song.id, song.server);
if (r && r.lyric) {
  text = r.lyric;
  song.tlyric = r.tlyric || "";        // ← 存下来了
  song.yrc = r.qrc || r.yrc || "";     // ← 逐字也存下来了
}
...
song._lines = XFLyrics.buildLines(text, song.yrc, { timeUnit: "ms" });   // ← 但这里没传 tlyric
```

`setLine()`（t5:709）的翻译分支：

```js
if (showTrans && line.trans && settings.showTranslation) {   // ← line.trans 恒为空
  const trans = document.createElement("span");
  trans.className = "lrc-trans";
  trans.textContent = line.trans;
```

而 `line.trans` 来自 `XFLyrics.buildLines` 的 `trans` 选项：

```js
const useTrans = !!o.trans;
const label = (l) => (useTrans && l.trans ? l.text + "(" + l.trans + ")" : l.text);
```

`l.trans` 是**LRC 行内翻译**（同一时间戳跟两行的那种），不是接口的 `tlyric`。
三模板调用时连 `trans: true` 都没传，更没有把 `tlyric` 传进 `buildLines` —— 所以：

**`song.tlyric` 只是个存着 881 个字符却没人读的字段。**

### 影响范围

| 模板 | 翻译开关 | `song.tlyric` 有值 | 渲染翻译 |
|---|---|---|---|
| classic | ✅ | ✅ | ✅（tlines 双轨） |
| t2 | ✅ | ✅ | ❌ |
| t3 | ✅ | ✅ | ❌ |
| t5 | ✅ | ✅ | ❌ |

桌面歌词（`desktop-lyrics.js:210`）走的是另一条路，`parser.parse(lyric, tlyric, yrc)` 有传翻译，
需要单独确认它渲染不渲染（本次未实测）。

## 4. 修法建议（未实施）

在三个模板的歌词加载处，把 `tlyric` 解析成独立时间轴，并在渲染时按时间匹配（照抄 classic 的
`translationFor` 思路即可）：

```js
// 1) 解析时多存一份翻译时间轴
song._lines = XFLyrics.buildLines(text, song.yrc, { timeUnit: "ms" });
song._tLines = song.tlyric ? XFLyrics.parseLrc(song.tlyric).map(l => ({ time: Math.round(l.time), text: l.text })) : [];

// 2) setLine 里按当前行时间取翻译
const t = showTrans && settings.showTranslation ? pickTrans(song._tLines, line.time) : "";
```

两个注意点：

1. **时间单位**：三模板用 `ms`（`timeUnit:"ms"`），`parseLrc` 输出毫秒，直接比即可
2. **翻译行数是原文的子集**（实测 45/49），必须按"时间 ≤ 当前行"取最近的一条，
   不能按下标对齐（会逐行错位）
3. t5 的舞台只渲染三行（上/中/下），翻译要挂在 `.lyric-main` 后面，
   字号要压小、颜色更淡，否则会挤占当前句的视觉重心
