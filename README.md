# 小风音乐 (Xiaofeng Music)

[中文](README.md) | [English](README_EN.md)

一款基于 Electron 的**全透明无边框**桌面悬浮音乐播放器。支持多源在线搜索、歌单导入、歌词（含翻译）、背景幻灯片与歌曲下载。

> 产品形态类似"桌面悬浮歌词"，但功能完整得多：既能当播放器用，也能挂在小窗当歌词/幻灯片背景。

## ✨ 功能特性

### 🎵 播放核心
- **多来源搜索**：网易云 / QQ 音乐 / 酷狗 / 歌曲宝 多源切换
- **歌单导入**：支持网易云、QQ 音乐歌单链接（含 QQ 短链自动展开）
- **自定义歌单**：新建 / 删除 / 加歌 / 移除 / 重命名
- **播放队列**：顺序 / 随机 / 单曲循环，队列可移除、插队（下一曲）、加歌单、下载
- **本地音乐**：扫描文件夹播放（mp3 / wav / flac / ogg 等）

### 🎤 歌词体验
- LRC 歌词解析 + 播放进度高亮
- **卡拉OK式逐字扫光**：QQ 音乐 / 网易云歌曲自动获取逐字数据，光带从左到右连续扫过（无需登录）
- **歌词翻译**（网易云官方翻译，可在设置中开关）
- 歌词**字号 / 系统字体 / 已播字颜色**自定义

### 🖥 桌面歌词
- **独立置顶悬浮窗口**：可拖动、可锁定、可关闭
- **控制栏**（悬停顶部显示）：打开主界面 / 上一首 / 播放暂停 / 下一首 / 锁定 / 设置
- **完整设置**：单行/双行、对齐、字体字号、已播/未播字色、文字透明度、描边、粗体、覆盖任务栏
- **卡拉OK式逐字扫光**（与主窗口一致，平滑连续）

### 🔑 网易云登录（可选）
- 右上角登录入口（**App 内嵌二维码扫码**：后台隐藏窗口读取官方登录页二维码，无需最小化软件）
- **我的歌单**：展示我创建/收藏的歌单（含"我喜欢的音乐"红心歌单），点击即播
- **每日推荐**：每日推荐歌曲 30 首 + 推荐歌单
- **最近听过**：本周 / 全部听歌记录切换
- **听歌打卡**：播放器里听的网易云歌曲（≥60s）自动上报，计入网易云"最近听过"并影响日推

### 🎧 QQ 音乐登录（可选）
- 右上角独立登录入口（**App 内嵌二维码扫码**，QQ 官方 ptlogin2 通道，安全可靠）
- **我的歌单**：我创建的 + 我收藏的歌单合并展示（红心歌单 ♥ 置顶），点击即播
- **每日推荐**：新歌推荐 + 热门推荐歌单
- 登录入口同时体现在**设置页**（可查看登录状态 / 退出）
- ⚠️ QQ 音乐登录态有效期约 1~3 天（QQ 官方限制），过期后需重新登录

### 🎧 酷狗音乐登录（可选）
- 右上角独立登录入口（**App 内嵌二维码扫码**，无风控，安全可靠；经典模板与新模板均支持）
- **我的歌单**：展示我的全部歌单（内嵌歌曲，点击即播）
- **每日推荐**：每日推荐歌曲，点击即播
- **酷狗播放**：免费歌曲直接完整播放；付费/VIP 歌曲匿名仅 60 秒试听（官方限制）
- 登录入口同时体现在**设置页**（可查看登录状态 / 退出）

### 🎨 视觉与背景
- **全透明无边框悬浮窗**，桌面任意位置放置
- **背景幻灯片**：图片 / 视频，切换间隔可调，支持预加载与淡入淡出
- 专辑封面模糊背景

### ⬇ 下载
- 一键下载 **MP3 + 歌词 + 封面** 到指定目录
- 下载音质可选（128 / 192 / 320kbps）
- 下载完成**右上角 Toast 提示**，点击直达文件所在文件夹

### 🖥 系统集成
- 系统托盘（后台驻留，**双击托盘图标显示主界面**）
- 音量持久化、播放状态持久化（重启恢复）
- 开机自启（可选）
- **设置面板分区导航**（外观 / 歌词 / 桌面歌词 / 幻灯片 / 励志句 / 常规 / 关于，点击滚动 + 自动高亮）

## 🚀 快速使用

1. 打开播放器（无边框悬浮窗，可用鼠标拖动）
2. 搜索歌曲，或粘贴歌单链接导入
3. 点击歌曲开始播放；点「设置」配置：
   - **音乐文件夹**：本地音乐播放目录
   - **图片/视频文件夹**：背景幻灯片素材
   - **下载目录**：歌曲保存位置
4. 歌词默认显示，可在设置中开启「显示歌词翻译」

> 详细说明见 [docs/使用手册.md](docs/使用手册.md)

## 🔧 开发与构建

```bash
# 安装依赖
npm install

# 开发运行
npm start

# 打包 Windows 安装包
npm run build
```

> ⚠️ 注意：本机 electron-builder 首次打包可能卡在 packaging 阶段（疑似杀软/IO 瞬时问题），停止后重试即可成功。

## 🛠 技术栈

| 组件 | 说明 |
|---|---|
| [Electron](https://www.electronjs.org/) | 33.x，桌面壳 |
| 原生 JavaScript | 无前端框架，纯 DOM 操作 |
| [@meting/core](https://github.com/metowolf/MetingJS) | 网易云 / QQ 音乐 API 封装 |
| [qrc-decoder](https://www.npmjs.com/package/qrc-decoder) | QQ 音乐 QRC 逐字歌词解密（ESM，extraResources 打包） |
| [font-list](https://www.npmjs.com/package/font-list) | 系统字体枚举（歌词字体选择） |
| [electron-builder](https://www.electronjs.org/docs/latest/tutorial/electron-builder) | Windows 打包 |

## 📁 项目结构

```
├── main.js            # 主进程（窗口/托盘/音乐API/下载）
├── preload.js         # 预加载（IPC 桥接）
├── renderer/          # 渲染进程（页面/歌词/幻灯片/播放器逻辑）
├── resources/         # 应用图标
├── scripts/           # 图标生成脚本
├── docs/              # 使用手册
└── build/             # 打包资源（icon.ico）
```
